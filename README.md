# AIRMS - Air Management System

## System Description
AIR MS is a web-based system developed to manage air-related
records and administrative tasks.

## Group Members
See [MEMBERS.md](MEMBERS.md).

## Technology Stack

- Frontend: HTML, CSS, JavaScript
- Backend: PHP
- Database: MySQL
- Code Editor: Visual Studio Code

## Installation

1. Install XAMPP.
2. Copy the project folder to htdocs.
3. Start Apache and MySQL.
4. Import the database through phpMyAdmin.
5. Configure includes/db.php.
6. Open the system in your browser.

## Repository
This repository contains the source code of AIR MS.
